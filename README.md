# @equos/browser-sdk
[Equos.ai](https://www.equos.ai) official BrowserJS SDK & React Components.


## Prerequisites
- Go to [Equos Studio](https://studio.equos.ai).
- Create an organization.
- Create a client Key.


## Installation
```bash
npm install @equos/browser-sdk
```
